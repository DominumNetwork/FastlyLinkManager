[?] FINDING YOUR API KEY

  1. Log in to your Fastly dashboard.
  2. Click the user menu (top right) and select Account.
  3. In the left sidebar, click the API tokens dropdown, and select Personal tokens.
  4. It may ask you to authenicate. Just input your email & password.
  5. Click the Create Token button.
  6. Give it a name, set Scope to Global, and Access to Global API access.
  7. Make sure to change the expiration to Never expire.
  8. Click Create Token. Copy the string provided.

[?] HOW TO USE THE SITE

  1. MAKING/SAVING Accounts: To make an account, You need to create an account name(Can be anything), and add your personal fastly API Key (Instructions can be found in the "[?] FINDING YOUR API KEY" Instructions).
  2. MAKING A LINK: To make links, you can make the service name whatever you want, make the subdomain whatever you want(NO "." WHEN MAKING), and set the host to any url you want the site to be. (Ex: example.com)
  3. EDITING LINKS: Editing links is the same process as making a link. Just find the link you made in the dropdown for that account, click edit, and change it how you'd like!
  4. DEACTIVATE/REACTIVATE LINKS: When deactivating a link, find the link you want to deactivate, then press "Deactivate". you will need to retype the service name that you originally set for that link (It will show in the modal if you forgot it). Reactivating is the same process!
  5. DELETING LINKS: When deleting links, you need to first Deactivate it. Afterwards, you can press delete on the link you want removed, and press "Delete" if you are 100% sure you want to delete it.
  6. FINDING MY LINKS: All links made by you will be located at the bottom of the page, in the dropdown menu for that account.
  7. SAVING ACCOUNTS/KEYS: You can export the .dnfs file to save your Accounts and api Keys just in case you need to reset your browser cookies and data, then import the .dnfs file afterward! If you clear browsing data before doing this, you could lose access to your accounts until you make a new api key!
