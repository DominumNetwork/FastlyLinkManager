[?] FINDING YOUR API KEY

  1. Log in to your Fastly dashboard.
  2. Click the user menu (top right) and select Account.
  3. In the left sidebar, click the API tokens dropdown, and select Personal tokens.
  4. It may ask you to authenicate. Just input your email & password.
  5. Click the Create Token button.
  6. Give it a name, set Scope to Global, and Access to Global API access.
  7. Make sure to change the expiration to Never expire.
  8. Click Create Token. Copy the string provided.
